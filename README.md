## 先搞清身份：老用户怎么判定，有没有“翻盘”机会

阿里云判定新老用户只看一件事：账号有没有产生过金额大于0的云产品订单。注册了三年从没买过东西，照样算新用户；注册第二天买了台ECS，立刻变老用户。和注册时长、消费金额都无关。

几条容易误判的规则单独列出来：

- **域名订单不算云产品购买记录。** 只买过域名、没买过云产品的账号，购买云服务器时仍然按新用户对待。
- **同一实名认证信息下的多个账号是共享身份的。** 只要其中任何一个账号买过付费云产品，同一名下的其他账号也会被判为老用户。想用新注册账号绕开老用户限制，在同一实名的场景下走不通。
- **“产品新用户”是老用户的翻盘机会。** 从未买过云服务器ECS或轻量应用服务器，或者这两类产品已到期超过13个月的账号，在云服务器这条产品线上按产品新用户对待，可以参与首购优惠。
- **长期不用也有专属通道。** 最近12个月名下未保有产品、也没有消费账单的老客户，可以走官方的老客户回归专区，拿回归专属价格。

最直接的验证方法是打开活动页点一次购买：结算页显示38元，说明系统判定你是新人；显示79元或其他价格，说明判定为老用户。比翻规则文档快得多。

顺带提一句，免费试用中心那套“先试用后购买”只对产品新客开放，老用户不用在这个入口上花时间。

## 续费、升配和付费模式：这些细节比选机型更影响总成本

同一台服务器，续费和付费策略不同，两年下来的花费能差出一截。几个规则明确、能直接执行的细节：

- **续费前先看续费专场。** 普通活动价机型续费时可能回到接近原价，续费专场会放出面向老用户的续费折扣；99元、199元这类标注“续费同价”的机型不用操心这一步。
- **长周期更便宜。** 包年包月买得越久折扣越深，3年付、5年付的年均成本明显低于1年付。适合架构成熟、确定长期运行的业务；架构还没定型的，先按年付，稳定之后再拉长周期。
- **升配比新购划算。** 给现有实例升级CPU、内存或存储时，剩余使用时长满180天享6.8折，不满180天享9折，费用按目标配置价与原配置价的差额乘以折扣、再乘剩余时长比例计算。需求超出99元款能力时，先算算升配和新购哪个便宜。
- **按量付费和抢占式实例留给特定场景。** 稳定业务用包年包月，短期突发用按量付费、用完即释，可中断的离线计算任务用抢占式实例，价格低到按量付费的一折左右。

## 几个高频问题

### 为什么我看不到38元/年的轻量服务器？

那是限时限量、每人限购1件的新人专享款，老用户的结算页显示的是其他价格。老用户的替代方案是99元续费同价款，或者经济型e实例的3.9折价——后者的配置选择更多。

### 服务器到期很久了，还能按新用户价买吗？

可以，但有时间门槛：云服务器ECS或轻量应用服务器到期超过13个月，再次购买云服务器时按产品新用户对待，能参与首购优惠；没满13个月的账号不适用。下单前先在活动页点一次购买验证身份，再决定走哪条优惠路径。

### 新注册一个账号买，能算新用户吗？

同一实名认证信息下的多个账号共享身份判定：任何一个账号有过付费云产品记录，其他账号也会被判为老用户。实名信息不同的账号各自独立判定，不过用别人的身份认证注册，后续实名、备案和账号安全都会踩坑，代价比省下的差价高。

### 99元款第二年续费会涨价吗？

不会。续费同价是这款机型的核心规则，活动页标注的续费有效期到2027年3月31日，在有效期内按99元的活动价续费。要留意的只有一件事：别拖到实例过期再处理。
